Resume privacy & AI data notice

Effective October 18, 2026. Veteran Career Path is operated by StreamSync Solutions. This adult-only (18+) resume program supplements the Privacy Policy, program purchase terms, and Cookie Policy.

Your information and choices

Resume imports (PDF, Word .docx and text) are extracted in your browser. Original files are not uploaded by this program. Structured fields can contain your chosen contact details, military and civilian employment, education, qualifications, awards, unclassified deployments, releasable clearance details, training, skills, languages and projects. Include only information you have permission to process. Never submit SSNs, birth dates, classified information, medical records, VA claim records, passwords, or sensitive military documents.

OpenAI and Anthropic

AI services used by Veteran Career Path include OpenAI and Anthropic. The current paid resume-program backend uses Anthropic; deployments configured with an OpenAI API key use OpenAI. Requesting an AI build sends the fixed resume text, target role, job announcement, application type and additional verified details through our server to the configured provider. OpenAI requests set store:false. That setting is not a guarantee of zero retention. Provider API security, processing and retention terms apply; we do not promise zero data retention or that submitted data never leaves your device. Neither provider's browser tracking script is loaded by this program.

AI processing requires its own agreement. Canceling a browser request cannot recall data already sent to a provider. AI can make factual mistakes. Review every title, duty, date, number, qualification, clearance status and application requirement. We do not guarantee employment, ATS results, federal acceptance, preference or eligibility.

Guest access

You may start without an email account. Drafts stay in this browser unless you choose device storage, save to an account, or start a paid AI build. Guest checkout creates a private, temporary Firebase sign-in identity with session-only browser persistence. Paid build inputs and results are stored for recovery under that identity. Guest access can be lost when the browser session ends, storage is cleared, or you sign out. Create a new email/password account from the guest session to keep that identity and its purchases. Signing in to a different existing account does not transfer guest purchases. Contact support with your transaction reference if access is lost. Never send card details.

Program accounts and optional saves

Free resume-program sign-in uses a separate named Firebase app session in the existing veteran-career-builder Firebase project. No main-site subscription or access code is required. Firebase authentication identities use the same project: if an email already exists there, sign in or reset its password. Main-site membership is not purchased, changed or required by this program.

Signing in does not automatically save your editor or structured background. Choosing “Also save the resume I submit to my account” at checkout stores the submitted resume text, title, context and formatting settings as a saved version. This option is off by default. Other Save actions remain explicit choices. Optional Save actions require the cloud-storage agreement. Program backgrounds and saved resumes use their own owner-only paths, separate from the main website profile and saved resumes. Saved editor versions include text, application context, title and formatting choices. Background saves include your structured fields. Firestore owner rules and server authorization restrict access; data is not automatically posted to a public profile. We do not enable Firestore offline disk caching.

Purchases and recovery storage

Beginning a $1.99 USD checkout requires a separate storage agreement. We save that build's fixed resume input and application context in private, server-owned Firebase records before checkout and save its AI review and rewritten result when successful. This lets you return after cancellation, payment, a connection failure or an AI failure without losing a purchase. Purchase records include your account ID, build ID, timestamps, status, amount, currency and Stripe session ID. Original imported files and full card details are not stored by this program.

Stripe receives purchase identifiers, price and payment information entered at Stripe-hosted checkout; our checkout request does not include resume text or service details. Stripe operates payment, fraud-prevention and financial recordkeeping under its own policies. Card entry occurs on Stripe, not our resume form. A failed AI build remains retryable under the same purchase. Formatting and downloading that result do not require another purchase.

Retention, export and deletion

Saved backgrounds, saved resumes, and checkout build inputs/results remain until deleted or an account-deletion request is processed. Delete individual saved resumes, Delete saved workspace background, or Delete data beside a purchase to remove that input and AI result from the active database. Deleting a purchase's data does not cancel payment, issue a refund or make the deleted result recoverable. Minimal transaction identifiers and accounting/security records may be retained for legal obligations and dispute handling. In-progress builds must finish before their data can be deleted.

Download my account data exports the program background and up to 50 saved editor versions. Purchase history displays up to 50 builds; each can reopen its original input and result for download. For a full export, older records, correction, deletion of all program data, or identity/account deletion, contact support. Tell us whether you mean only this resume program or your shared Firebase identity, since deleting the identity affects other website tools. The main Privacy Policy's deletion timelines and backup-retention provisions apply. Deleting data does not erase downloaded files, other devices, financial records or provider-retained processing records.

Cookies, logs and security

See the Cookie Policy for essential account storage, opt-in device drafts, payment cookies and separate main-site preferences. This workspace has no analytics, advertising, tracking pixels or social embeds. TikTok opens only when you choose the external link. Account-specific abuse counters do not contain resume text. Application code does not log resume bodies, AI results, credentials or identity tokens. Hosting and providers may retain operational connection/security logs. Data travels over HTTPS; authorized operators and providers may access it as needed to operate, secure and support the service. No system guarantees absolute security.
